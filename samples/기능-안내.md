# MarkView 기능 안내 📘

이 문서는 **MarkView** 가 지원하는 모든 표현을 한 번에 확인하기 위한 예제입니다.
Claude 가 만들어 주는 마크다운 문서에서 흔히 쓰이는 요소를 전부 담았습니다.

> 왼쪽에서 이 문서를 편집하면 오른쪽 미리보기가 즉시 바뀝니다.
> 왼쪽 **목차** 패널에서 원하는 절로 바로 이동할 수 있습니다.

## 5. Mermaid 다이어그램

### 순서도 (flowchart)

```mermaid
graph TD
    A[문서 열기] --> B{마크다운인가?}
    B -- 예 --> C[파싱]
    B -- 아니오 --> D[안내 메시지]
    C --> E[HTML 변환]
    E --> F[정화 · 살균]
    F --> G[미리보기 표시]
    G --> H{다이어그램 있음?}
    H -- 예 --> I[Mermaid 렌더링]
    H -- 아니오 --> J[완료]
    I --> J
```

### 시퀀스 다이어그램

```mermaid
sequenceDiagram
    participant U as 사용자
    participant R as 렌더러
    participant M as 메인 프로세스
    U->>R: 파일 드래그 앤 드롭
    R->>M: readFile(경로)
    M-->>R: 본문 + 폴더 정보
    R->>R: 마크다운 → HTML
    R-->>U: 미리보기 표시
```

### 간트 차트

```mermaid
gantt
```

## 6. 수식 (KaTeX)

인라인 수식: 아인슈타인의 $E = mc^2$ 와 이차방정식의 근 $x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$.

블록 수식:

$$
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$

$$
\begin{pmatrix} a & b \\ c & d \end{pmatrix}
\begin{pmatrix} x \\ y \end{pmatrix}
=
\begin{pmatrix} ax + by \\ cx + dy \end{pmatrix}
$$

통화 표기는 수식으로 오해하지 않습니다: 이 제품은 $100 이고 저 제품은 $250 입니다.

## 7. 코드 블록

```python
def fibonacci(n: int) -> list[int]:
    """피보나치 수열을 n개 생성한다."""
    seq = [0, 1]
    while len(seq) < n:
        seq.append(seq[-1] + seq[-2])
    return seq[:n]

print(fibonacci(10))
```

```javascript
const 문서목록 = await fetch('/api/docs').then((r) => r.json());
```

```sql
SELECT d.name, COUNT(*) AS 개수
FROM documents d
JOIN revisions r ON r.doc_id = d.id
WHERE d.created_at >= '2026-01-01'
GROUP BY d.name
ORDER BY 개수 DESC;
```
